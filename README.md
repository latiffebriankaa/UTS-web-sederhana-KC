# UTS Web Sederhana - Kecerdasan Buatan

Aplikasi web sederhana untuk skrining awal gangguan tidur menggunakan pendekatan rule-based (IF-THEN) dengan metode forward chaining.

## Isi Proyek

- index.html: Struktur halaman kuis dan hasil
- style.css: Tampilan antarmuka yang sederhana dan responsif
- app.js: Data pertanyaan, rule base, mesin inferensi, dan interaksi UI

## Cara Menjalankan

1. Buka folder proyek ini.
2. Jalankan file index.html di browser.
3. Jawab semua pertanyaan sampai hasil muncul.

## Catatan
Hasil yang ditampilkan adalah skrining edukasi awal, bukan diagnosis medis.
